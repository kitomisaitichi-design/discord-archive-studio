# Reading, rendering and release corrections

- When maintenance cannot observe a rest between short tasks, inspect the actual worker and temporarily hold only future starts; restore the hold conditionally so a genuine new batch rest survives.
- When adding reading controls, measure the conversation space at the actual window size and move secondary tools into a contextual panel.
- When adding a theme, verify message text as well as form controls; inherited fixed colors can leave Sepia text unreadable.
- When a message-jump API has exact semantics, preserve them and make preceding context an explicit option.
- When benchmarking manually supplied snapshots, close the fixture's live event stream first so initial connection events cannot replace the measured state.
- When caching person-filtered totals, include explicit identity links in invalidation as well as channel generations.
- When a saved reading query changes, discard its old position; restore stable message cursors only within the matching context.
- When checking browser motion or viewports, reset test emulation afterward and confirm the dimensions of the intended tab.
- When checking media retention, use a long enough fixture to observe playback across the operation; a finished short MIDI song does not prove playback was retained.
