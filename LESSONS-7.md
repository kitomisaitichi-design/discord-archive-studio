# Lessons

- When patching a document, read its actual anchor and apply hunks in source order; do not infer headings from filenames.

- When custom emoji tokens appear in saved text, resolve graphics through one persistent registry keyed by emoji ID, across names, messages, servers and archives.
- When many tiny assets arrive, group local ZIP updates and reuse the message index; never refetch history or query server members to render an emoji.
- When emoji artwork is unavailable, render the captured name clearly and retain the raw token in canonical data and code snippets.
